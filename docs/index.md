# Ekko documentation

Understand Ekko, choose your audience, and evaluate the scope of an integration.

Canonical URL: https://ekko.zone/docs/
Reviewed: 2026-09-06
Availability: Product concepts and scope; not a release-availability statement

Ekko helps people understand their onchain positions, discover opportunities, recognize problems, and prepare valuable actions. Teams deliver that value to their users; Individuals use Ekko directly for their own interests.

## User guides

- [Teams](https://ekko.zone/docs/guides/teams/): understand provider coverage, operational monitoring, and notification records.
- [Individuals](https://ekko.zone/docs/guides/individuals/): understand direct monitoring and how it differs from receiving a provider's alerts.

The library currently explains concepts and evaluation boundaries. Verified Team and Individual setup tutorials are not yet available here. Contact [support](mailto:support@ekko.zone) for help with your current release.

## Developer integrations

Read the [integration overview](https://ekko.zone/docs/integrations/) before planning a rollout. It explains which relationship an integration serves and the evidence to request for installation, authentication, and delivery.

## Understand a result

Start with [product concepts](https://ekko.zone/docs/concepts/), use the [delivery proof model](https://ekko.zone/docs/delivery-proof-model/) to assess a notification, or find [troubleshooting help](https://ekko.zone/docs/troubleshooting/). The [changelog](https://ekko.zone/docs/changelog/) records changes to this library.

Every article has a Markdown download. [The AI tools index](https://ekko.zone/llms.txt) links to the same content in Markdown, including availability notes and limitations.
