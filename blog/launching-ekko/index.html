Ekko Is Live

Governed user messaging for onchain products, shipped.

TL;DR

  • Ekko lets teams describe onchain moments in plain English and review the trigger logic.
  • Teams can resolve affected wallets, accounts, users, and cohorts before delivery.
  • Messages can route through the channels users, operators, and support already check.
Important
If you only do one thing: describe a missed notification moment, confirm the parsed trigger logic, and choose who should receive the message.

What You Can Do Today

Ekko’s first release focuses on fast time-to-first-useful-message:

  • Create message plans using natural language and review what Ekko understood.
  • Use supported wallet and contract activity as factual trigger context.
  • Route governed notifications when conditions are met.

Getting Started

  1. Create your account: https://app.ekko.zone
  2. Describe a message moment like: Notify affected users when a supported contract event changes their position
  3. Choose the affected audience and reachable delivery channels
